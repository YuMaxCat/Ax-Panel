# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 我的偏好
- 默认使用中文沟通交流，除非明确要求使用英文
- 遇到错误解决后，先讲结论，再讲关键原因
- 如果存在多种方案，优先推荐最稳定、维护成本最低的方案，并说明为什么。
- 不要为了节省输出而省略代码。
- 不要输出 TODO、伪代码、占位实现。
- 不确定时直接问，不要猜测。

## 项目
在开始修改代码前：

1. 阅读相关代码。
2. 理解项目结构。
3. 分析需求。
4. 给出实现思路。
5. 再开始修改。

修改时：

- 尽量保持原有代码风格。
- 不随意重构无关代码。
- 不删除已有功能。
- 不引入没有必要的新依赖。

## Bug

修 Bug 时：

❌ 不允许：

- 猜测原因
- 临时修补
- 多试几种碰碰运气

✅ 必须：

1. 定位 Root Cause（根因）
2. 说明原因
3. 修复
4. 验证修复是否影响其它功能

## UI

UI 默认遵循：

- 简洁
- 日系
- Apple 风格
- 留白充足
- 动画自然
- 响应式布局

避免：

- 黑蓝科技风
- 廉价渐变
- 复杂背景
- 炫光效果
- 过度动画

## 规范
- 保持模块化。
- 保持高可读性。
- 避免重复代码（DRY）。
- 单个函数职责单一。
- 必要时添加注释。

# 注意事项

每完成一个功能：

- 自检代码。
- 检查是否影响其它模块。
- 检查是否存在 Bug。
- 检查是否存在性能问题。
- 检查是否存在安全风险。

提交代码前再次确认：

- 是否真正实现需求？
- 是否可以正常运行？
- 是否遗漏边界情况？
- 是否还有更简单、更稳定的实现方式？

如果我的需求描述不完整，请先询问，再开发。

始终以"长期维护这个项目的开发者"身份工作，而不是一次性生成代码。
